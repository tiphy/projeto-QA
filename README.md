Sistema confiável para alocação de salas, professores e materiais sem conflitos de agendamento.

- **Banco de Dados:** SQLite (com Entity Framework Core)
- **Ferramentas de Testes:** 
  - xUnit (Testes Unitários e Integração)
  - Reqnroll / SpecFlow (BDD / Cenários Gherkin em Português)
